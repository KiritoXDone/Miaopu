# 桌面小部件

## 范围与设计

采用 Android AppWidgetProvider / RemoteViews，提供两个独立入口：喵扑·单场赛况（2×2）和喵扑·近期赛程（4×2）。以已确认的设计稿为参考，使用系统字体、蓝色强调色、圆角和 16dp 内边距（紧凑布局为 12dp），适配深浅色。2×2 卡片按宿主区域的短边绘制正方形，在两列两行的占位中居中。近期赛程保留原有单行排列、标题和页脚；可用宽度足以容纳两份原有行布局时，使用等宽双列，左侧历史、右侧进行中与近期，各最多三场。不添加分区标题或独立卡片。

双列切换宽度来自原有行布局的测量、内边距和列间距，不按设备型号或屏幕像素设断点，并为系统大字体预留空间。Android 12 及以上优先使用桌面报告的实际尺寸组合；旧版或未报告尺寸的桌面分别生成横竖屏布局。窄尺寸保持原有单列优先级；高度不足或大字体时每列减少至一或两场。一侧不足三场时保持行对齐，无数据的一侧显示对应空态。

遵循 [Xiaomi HyperOS 小部件设计规范](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1664) 的信息层级与视觉原则，通过系统的“安卓小部件”入口添加；不包含小米小部件中心的审核或上架流程。

## 内容与交互

- 复用应用的赛事订阅。保留历史与近期各三场候选，避免近期比赛占满列表后丢失历史；历史按结束比赛的开赛时间倒序，近期仍为进行中优先、其余按开赛时间升序。单场与单列布局仍按进行中、即将开始、最近结束排序；过滤 48 小时以前的结果、7 天以后的比赛和超过 12 小时的旧进行中标记。
- 比分与队标来自赛程字段。未开始时显示 VS；没有队标或图片加载失败时显示队名首字。不推断 BO3 / BO5 或当前局数。
- 有评分入口的比赛直接打开比赛详情，否则进入该项目赛程。完整赛程入口进入赛事页。
- 首次加载、无比赛、离线、失败和缓存状态有独立提示。2×2 时间显示具体月日和时分，4×2 跨日时间使用 +1、+2 天数上标，游戏类型紧接时间右侧同一行显示，旧数据标注缓存和获取时间。

## 更新与存储

- 应用内赛程加载结果同步写入小部件缓存；订阅变化立即重新筛选。应用回到前台时重新推送缓存并安排刷新，恢复被后台冻结策略跳过的首次更新。
- AppWidget 的周期更新为 30 分钟，实际执行受系统后台限制影响，不保证实时比分。
- 手动刷新和周期更新交给同一个 JobScheduler 任务，等待网络可用；两个尺寸共用数据，不为每个实例重复请求。
- 本机缓存仅含公开赛程信息，不含账号或评论。每项目历史与近期各最多 30 场、合计最多 60 场；每次为六场候选加载最多 12 个队标，缩略图为 96px，最多保留 64 张。
- 同一项目较早开始的请求不会覆盖较新请求的结果；失败保留上次成功的数据。待处理跳转会等应用导航初始化后执行。

## 验证

```bash
./gradlew testDebugUnitTest assembleDebug assembleDebugAndroidTest lintDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w dev.kiritoxd.miaopu.debug.test/dev.kiritoxd.miaopu.widget.WidgetTestRunner
```

单元测试覆盖比赛筛选、去重、过期状态、比分与日期表达和缓存序列化。设备测试使用实际 RemoteViews 渲染两种尺寸、两种主题、普通/大字体、最小高度及五种数据状态，导出图片供布局检查。已在 HyperOS 桌面确认两种尺寸的添加、真实赛程与队标显示。60 组实机渲染覆盖跨日时间、最小高度和大字体，并检查文字高度与父容器边界；后台周期执行仍受系统策略限制。

双列改动新增两组候选独立限额的单元测试；设备测试扩展到平板宽度、紧凑双列、大字体双列、单侧空态和两侧场数不等，检查分组、行对齐、横向边界及宿主尺寸选择。上述 60 组实机结果属于原有单列版本，不能作为双列版本的设备验证结果。

若系统冻结策略拦截首次小部件广播，桌面可能停留在初始加载画面。打开喵扑可恢复更新；持续后台刷新仍受设备的冻结和省电设置限制。

## 进行中演示

测试 APK 支持临时将桌面首场比赛显示为进行中、比分 1:1，不修改真实赛程缓存。刷新后恢复实际数据：

```bash
adb shell am instrument -w -e preview_live true dev.kiritoxd.miaopu.debug.test/dev.kiritoxd.miaopu.widget.WidgetTestRunner
```

2×2 底部显示赛事类型；4×2 使用时间、分隔符、赛事类型，左队队标靠近比分，右队队标位于队名前。
